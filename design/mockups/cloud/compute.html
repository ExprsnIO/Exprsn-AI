GPU compute pools in the cloud

A cloud node group is a pool like any other: the gateway places approved models on its instances, the memory planner and slot leases work unchanged, and instances join over mutual TLS with certificates from the Exprsn-AI CA. What the cloud adds is elasticity: node groups scale to zero when idle, run on spot capacity where the provider offers it, and are checked against quotas and the account's budget before they grow.
