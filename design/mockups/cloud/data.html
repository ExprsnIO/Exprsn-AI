Managed databases, caches and object stores

One screen, #/cloud-data, lists every database, cache and object store Exprsn-AI provisioned or discovered in a connected account. Each one has a role: the platform's own database or Redis, a tenant data connection, or an object store. Provisioning goes through the same plan, apply and verify path as a deployment (B-101), so a database is a resource in the journal with a cost estimate, drift checks and deletion protection.

Example data for the Northwind tenant on Monday 28 Sep 2026. Account IDs, hostnames and prices are illustrative, not provider quotes.
