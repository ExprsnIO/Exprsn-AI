Cloud deployments and integrations

Exprsn-AI 2.0.0 works with public clouds in both directions. It deploys itself (application, PostgreSQL, Redis and Ollama GPU nodes) to AWS, Azure or DigitalOcean, with Cloudflare as the front door and as an optional app tier. A running install can also use those clouds' services: model APIs as gateway backends, GPU node groups as pools, and managed databases as its own database or as data connections. Every change is planned, priced and reviewed before the deploy worker applies it with the providers' own SDKs and APIs.

How the server talks to the clouds

No Terraform and no CLI in the request path: the deploy worker calls each provider directly through an adapter, records every step in the operation journal and resumes from it after a restart (B-101).

Design rules carried over
  • Native SDKs and REST APIs, not Terraform: AWS SDK v3, Azure ARM SDKs, DigitalOcean API v2 (no official Node SDK) and Cloudflare API v4, each behind one CloudProvider adapter.
  • Plan, then apply, then verify. An apply runs only the plan the reviewer saw, identified by its hash; a changed plan needs a new review.
  • Dual control for adding or removing an account, changing its credential mode, raising a region's label ceiling, destroying protected data and overriding a budget.
  • Labels and zones decide where data may go: each region has a label ceiling and a zone; restricted data stays on premises unless a dual-controlled override says otherwise.
  • Exprsn-AI identity, guardrails and the gateway stay authoritative. Cloudflare Access, Bedrock Guardrails and AI Gateway are extra layers, never replacements.
  • pgvector stays the vector store; Cloudflare Vectorize is not used.
Two directions
Deploy Exprsn-AI itself
Kubernetes with the Helm chart, VMs with the bare-metal installer, or container platforms; managed PostgreSQL and Redis; GPU nodes running Ollama; DNS and TLS through ACME or Cloudflare (B-102, B-109).
Use cloud services from a running install
Bedrock, Azure AI Foundry, DigitalOcean GenAI and Workers AI as model backends (B-105, needs B-43); GPU node groups as pools (B-104); managed databases as data connections (B-103).
Pay for it knowingly
An estimate before every apply, monthly budgets with a hard stop on new resources, billing ingestion and showback per workspace (B-106).
