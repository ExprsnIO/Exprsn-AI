Cloud model backends on the Models screen

Bedrock, Azure AI Foundry, DigitalOcean GenAI and Workers AI models join the catalogue as server-held entries (format: server, from epic B-43's ModelServer interface): no weights and no digest, but the same licence record, conformance run, dual-control approval and label ceiling as an Ollama model. The Models screen gains a provider filter and a cloud catalogue import; nothing about profiles, guardrails or metering changes for the person chatting.

Example data on Monday 28 Sep 2026. Model prices are illustrative, not provider quotes.
