Deployments

A deployment is Exprsn-AI itself running in a cloud: an app tier, its database, cache and object store, optional GPU pools and a front door. The wizard produces a plan; the plan is priced, diffed and approved; the deploy worker applies it and verifies the result. Afterwards the detail page watches for drift and runs upgrades and rollbacks the same way.
