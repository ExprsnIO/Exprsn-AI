Model and dataset import wizard

One guided path from a public repository to a registered draft model, a versioned training dataset, a classifier evaluation set or a knowledge set. It extends the Model catalog, Training, Classifiers and Knowledge screens instead of replacing them: every result lands where those screens already govern it, with the licence, label, digest and requester recorded on the manifest.

Design rules carried over
  • Weights enter only through the signed import path: GGUF and safetensors are accepted, pickle checkpoints are refused before anything is written.
  • Connected deployments fetch through the staging proxy; air-gapped ones queue the request for the weekly bundle. The wizard is the same, only step 6 differs.
  • Licences are recorded on the manifest and checked against the tenant allow list. Non-commercial terms raise an exception for legal; an unknown licence waits for review before approval.
  • Datasets are scrubbed, hashed and versioned exactly as Training does today; a knowledge set is a knowledge base whose single source has kind dataset.
  • Every control works in light and dark themes with the console's tokens; copy stays plain and specific.

Entry points on the existing screens

The wizard opens from the four screens it enhances, with the kind and destination preselected. It also has three palette commands and its own route for the Imports queue and the Repositories registry.

Models

Opens the wizard for a model with destination Model catalog. Result: a draft tag with digest, licence and pools, waiting for evals.

Training, Datasets tab

Opens the wizard for a dataset with destination Training dataset. Result: a scrubbed, hashed version with splits and a scrub report.

Classifiers

Destination Classifier eval set: rows become the evaluation set of a new or existing classifier; a classifier model imports as an engine.

Knowledge

Destination Knowledge set: a knowledge base built from the rows, with column mapping, embedding model, label floor and a refresh schedule that follows the publisher.

States to design from this page

Gated repository
A gated Hugging Face model lists no files until the licence gate is accepted with the recorded token. Next stays disabled.
Pickle refused
The repository publishes only pytorch_model.bin. The format check fails, nothing is written and no tag is registered.
Licence outside policy
A CC BY-NC dataset is outside the tenant allow list. The import waits on a licence exception from legal.
PII in the preview
The PII classifier flags columns in the 2,000-row sample. The scrub masks free text and generalises quasi-identifiers before rows are stored.
Dataset over quota
A multi-terabyte dataset exceeds the 500 GB quota. Only a streamed sample or a smaller configuration can be imported.
Source rate limited
ModelScope is rate limiting the staging proxy. Browsing falls back to the weekly snapshot and downloads queue with backoff.
Air-gapped: joins the bundle
With no outbound path, the request joins the weekly bundle. Staging fetches, scans and signs; the item appears after the diode transfer.
Knowledge set created
A monthly Eurostat table becomes a knowledge set with a refresh schedule; rows are documents with citations back to the row.
